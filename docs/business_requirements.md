# Бизнес-требования к приложению

## Назначение
Приложение автоматизирует расчет базовых финансовых показателей, избавляя пользователя от ручных подсчетов в Excel и предоставляя готовые выводы.

## Основной функционал
- Загрузка исходных данных о доходах и расходах.
- Автоматический расчет рентабельности и других заданных метрик.
- Визуализация результатов в виде понятных графиков.

## Условия использования
- Приложение должно запускаться на Windows без сложной настройки окружения.
- Код должен быть структурирован, документирован и храниться в Git.
- Результат работы должен быть понятен пользователю без глубоких технических знаний.
